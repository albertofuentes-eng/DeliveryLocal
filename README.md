# DeliveryLocal

Plataforma de delivery local desarrollada como proyecto universitario.

## Tecnologías

- ASP.NET Core Web API (.NET 8)
- React Native (Expo)
- SQL Server
- Entity Framework Core
- SignalR
- JWT
- Firebase Cloud Messaging

## Estructura

- DeliveryAPI
- DeliveryCliente
- DeliveryRepartidor
- DeliveryAdmin
- Database
- Docs
